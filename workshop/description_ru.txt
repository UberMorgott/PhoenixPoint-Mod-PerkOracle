[h1]PerkOracle[/h1]
[b]Предпросмотр (только для чтения) случайных «персональных» перков бойца — для Phoenix Point, отдельно или с TFTV. Плюс отключённая по умолчанию замена перков.[/b]

[b]PerkOracle не создаёт, не добавляет и не меняет перки.[/b] Часть перков «персональной» ветки выпадает случайно — это [b]собственная система игры[/b], а не функция мода. PerkOracle лишь [b]читает[/b] эти данные и наглядно их показывает.

[hr][/hr]

[h1]Что делает мод[/h1]
[list]
[*][b]Подсвечивает случайные перки[/b] — на экране прогрессии ячейки персональной ветки со случайным перком получают синий оттенок. Видно, что выпало случайно, а что — из фиксированной классовой ветки.
[*][b]Всплывающая «вики» кандидатов[/b] — наведите курсор на случайную ячейку и нажмите [b]отмену[/b] (правый клик / [b]Esc[/b]), чтобы открыть окно со [i]всеми[/i] перками для слота — с нативной иконкой и подсказкой. Окно временное, ничего не меняет; повторная отмена закрывает его.
[/list]

[h1]Опция: замена перков (по умолчанию выключена)[/h1]
[list]
[*][b]AllowPerkSwap[/b] — по умолчанию [b]ВЫКЛ[/b]; «из коробки» мод только для чтения. Включите опцию в настройках — тогда [b]левый клик[/b] по перку в вики заменит [b]уже выученный[/b] перк в слоте на другой существующий.
[*][b]Новые перки не создаются[/b]: меняется лишь то, какой существующий перк занимает уже открытый слот. Без вашего согласия ничего не меняется.
[/list]

[h1]Требования[/h1]
[list]
[*][b]Phoenix Point[/b] — работает с базовой игрой [b]отдельно[/b].
[*][b]Terror From The Void (TFTV)[/b] — [b]полностью совместим, но не обязателен[/b]. С TFTV мод читает данные о случайных перках из TFTV; иначе — пул персональных перков базовой игры.
[/list]

[h1]Поддерживаемые языки[/h1]
8 языков: EN, 简体中文, FR, DE, IT, PL, RU, ES.

[h1]Как пользоваться[/h1]
[list=1]
[*][b]Подпишитесь[/b] на PerkOracle в Мастерской. (С TFTV — установите и его; PerkOracle загрузится после.)
[*]Запустите Phoenix Point и [b]включите PerkOracle[/b] в менеджере модов.
[*]Откройте экран прогрессии бойца, найдите ячейку с синим оттенком и нажмите [b]отмену[/b] (правый клик / Esc).
[/list]
