[h1]Oracle[/h1]
[b]An in-game advisor for Phoenix Point. It surfaces information the game normally hides, right where you make decisions, as on-hover hints and tooltips. Standalone on the base game, fully compatible with TFTV.[/b]

[hr][/hr]

[h1]Updating from PerkOracle? Read this first[/h1]
[list]
[*][b]The mod was renamed from "PerkOracle" to "Oracle"[/b] (same Steam page, same item, same subscription). Because its internal id changed, after the update you may need to open the in-game [b]Mods[/b] menu and re-enable your mods once. Nothing is lost; this is a one-time activation refresh.
[*][b]The mod's own in-game research resets once.[/b] The optional "perk swap" unlock will show as not-yet-researched again after this update. To get it back, either research it again in-game or simply turn that feature off in the mod settings (it is optional). [b]Your resources, perks, and soldiers are not touched[/b]. Only the mod's own research flag resets, this one time. Future updates will not do this again.
[/list]

[h1]What it does[/h1]
Oracle has four helpers.
[list]
[*][b]Perk foresight.[/b] On the ability-progression screen, the random ("rolled") personal perks are highlighted, so you can tell at a glance which came from the roll and which from the fixed class track. Open a perk wiki popup to see every perk that could have landed in a slot, with the game's own icons and tooltips. An optional, research-gated perk swap lets you change a learned perk for another existing one. You can also open a class wiki from a trained class skill to browse every class's ability track and perk slots.
[*][b]Event choice preview.[/b] Hover an answer option in a geoscape exploration event and a tooltip shows that choice's outcome [i]before[/i] you pick it: resources, reputation, soldier stamina and HP, items, sites revealed, and more. Values match what the game will actually grant, including TFTV's modifiers, and the labels use the game's own localized text.
[*][b]Subclass preview.[/b] When you pick a soldier's second class at level-up, clicking a subclass first shows its full perks and abilities right in the confirmation, with the game's own icons and tooltips, so you see what you are getting before you commit. Unresearched subclasses are shown greyed out and can be previewed the same way.
[*][b]Dismantle yield.[/b] Item tooltips (equipment, geoscape, tactical, mutation) show a native "DISMANTLE" row with the resources you recover by scrapping an item, matching TFTV's prorated refund when TFTV is installed.
[/list]

[h1]Compatibility[/h1]
[list]
[*][b]Standalone.[/b] Works with base Phoenix Point on its own, nothing else required.
[*][b]Terror From The Void (TFTV).[/b] Fully compatible. With TFTV installed it reads TFTV's per-slot data and matches TFTV's reward math; otherwise it uses the base game's data.
[*][b]Class-adding mods.[/b] Works alongside mods that add classes (new Officer, extra classes, and so on).
[/list]

[h1]Supported languages[/h1]
English, 简体中文 (Simplified Chinese), Français, Deutsch, Italiano, Polski, Русский, Español. 8 languages.

[h1]How to use[/h1]
[list=1]
[*][b]Subscribe[/b] to Oracle on the Workshop. (If you use TFTV, install it too; Oracle loads after it.)
[*]Launch Phoenix Point and [b]enable Oracle[/b] in the in-game mod manager.
[*]Open a soldier's ability-progression screen and hover a rolled perk, or hover an answer option in an exploration event.
[/list]
