[h1]PerkOracle[/h1]
[b]A read-only in-game preview of which random "personal" perks a soldier could have rolled. For Phoenix Point, standalone or with TFTV.[/b]

In Phoenix Point, some perks on the "personal" track are rolled randomly for each soldier. That randomness is the game's own system (vanilla and TFTV), not something this mod adds. PerkOracle only reads that data and shows it to you. It does not generate, add, or change any perks.

There is also an optional perk swap, off by default, for players who want more control.

[hr][/hr]

[h1]What it does[/h1]
[list]
[*][b]Highlights rolled perks.[/b] On the ability-progression screen, personal-track cells whose perk was randomly rolled get a blue tint, so you can tell at a glance which ones came from the random roll and which from the fixed class track.
[*][b]Candidate "wiki" popup.[/b] Hover a rolled (blue) perk and [b]right-click[/b] it to open a popup listing [i]every[/i] perk that could have landed in that slot, each with the game's own icon and tooltip. The popup changes nothing; right-click again to close it.
[/list]

[h1]Optional: Perk Swap (off by default)[/h1]
[list]
[*][b]AllowPerkSwap[/b] is [b]OFF[/b] out of the box, so PerkOracle stays strictly read-only. Turn it on in the mod's Settings, and [b]left-clicking[/b] a perk in the wiki replaces an already-learned perk in that slot with another existing perk. It only swaps which existing perk occupies a slot you have already unlocked.
[*][b]Optional research gate.[/b] You can require a one-time "Operative Reconditioning" research before soldiers can be retrained. Toggle it in the mod settings.
[/list]

[h1]Compatibility[/h1]
[list]
[*][b]Standalone.[/b] Works with base Phoenix Point on its own, nothing else required.
[*][b]Terror From The Void (TFTV).[/b] Fully compatible. With TFTV installed it reads TFTV's per-slot random-perk data; otherwise it uses the base game's personal-perk pool.
[*][b]Class-adding mods.[/b] Works alongside mods that add classes (new Officer, extra classes, and so on).
[/list]

[h1]Supported languages[/h1]
English, 简体中文 (Simplified Chinese), Français, Deutsch, Italiano, Polski, Русский, Español. 8 languages.

[h1]How to use[/h1]
[list=1]
[*][b]Subscribe[/b] to PerkOracle on the Workshop. (If you use TFTV, install it too; PerkOracle loads after it.)
[*]Launch Phoenix Point and [b]enable PerkOracle[/b] in the in-game mod manager.
[*]Open a soldier's ability-progression screen, hover a rolled (blue) perk and [b]right-click[/b] it.
[/list]
